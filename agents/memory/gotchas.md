## Backend Gotchas

### ❌ Forgetting `await` with Async Functions
```python
# Bad
result = session.execute(query)  # Returns coroutine, not result

# Good
result = await session.execute(query)
```

### ❌ Not Filtering by user_id
```python
# Bad - Returns all users' tasks
query = select(Task).where(Task.id == task_id)

# Good - User isolation enforced
query = select(Task).where(Task.id == task_id, Task.user_id == user_id)
```

### ❌ Using 403 Instead of 404 for Cross-User Access
```python
# Bad - Reveals task exists
if task.user_id != user_id:
    raise HTTPException(403, "Forbidden")

# Good - Prevents enumeration
if task is None or task.user_id != user_id:
    raise HTTPException(404, "Task not found")
```

### ❌ Missing Type Hints
```python
# Bad
async def get_task(session, id):
    ...

# Good
async def get_task(session: AsyncSession, id: int) -> Task:
    ...
```

## Frontend Gotchas

### ❌ Missing "use client" Directive
```typescript
// Bad - useState in Server Component
export default function Page() {
  const [state, setState] = useState();  // Error!
}

// Good
"use client";

export default function Page() {
  const [state, setState] = useState();  // Works!
}
```

### ❌ Custom CSS Instead of Tailwind
```css
/* Bad - Don't create custom CSS */
.button-primary {
  background: blue;
}

/* Good - Use Tailwind utilities */
className="bg-blue-600 hover:bg-blue-700"
```

### ❌ Direct State Mutation
```typescript
// Bad
tasks.push(newTask);  // Doesn't trigger re-render

// Good
setTasks([...tasks, newTask]);
```

### ❌ No Error Handling in Async Functions
```typescript
// Bad
const handleCreate = async () => {
  await taskApi.create(data);  // What if it fails?
};

// Good
const handleCreate = async () => {
  try {
    await taskApi.create(data);
  } catch (err) {
    setError(err.message);
  }
};
```

## Database Gotchas

### ❌ Wrong asyncpg Connection String
```env
# Bad - sslmode not supported by asyncpg
DATABASE_URL=postgresql+asyncpg://host/db?sslmode=require

# Good
DATABASE_URL=postgresql+asyncpg://host/db
```

### ❌ SQLModel Types in Alembic Migrations
```python
# Bad - Generated by autogenerate
sa.Column('title', sqlmodel.sql.sqltypes.AutoString(), ...)  # NameError

# Good - Manually fix
sa.Column('title', sa.String(length=255), ...)
```

## Testing Gotchas

### ❌ Using @pytest.fixture for Async Fixtures
```python
# Bad
@pytest.fixture
async def client():
    ...

# Good
@pytest_asyncio.fixture
async def client():
    ...
```

### ❌ Not Mocking External Services
```python
# Bad - Calls real OpenAI API in tests
response = await client.post("/api/tasks/1/suggestions")

# Good - Mock the API call
mocker.patch("app.ai.suggestions.suggest_subtasks", return_value=["Sub1", "Sub2"])
```

## Security Gotchas

### ❌ Trusting User-Supplied user_id
```python
# Bad - user_id from request body
@router.post("/tasks")
async def create_task(task_in: TaskCreate):
    task = Task(**task_in.dict())  # user_id could be forged!

# Good - user_id from JWT
@router.post("/tasks")
async def create_task(
    task_in: TaskCreate,
    user_id: str = Depends(get_current_user_id)  # From JWT
):
    task = Task(**task_in.model_dump(), user_id=user_id)
```

### ❌ Storing Secrets in Code
```python
# Bad
API_KEY = "sk-proj-abc123"

# Good
from app.config import settings
api_key = settings.openai_api_key  # From .env
```

## General Gotchas

```
❌ "I'll implement auth"
✅ "I'll read @specs/features/auth.md, then implement"
```

### ❌ Skipping PHR Documentation
```
❌ Finish work without creating PHR
✅ /sp.phr to document decisions and changes
```

### ❌ No Accessibility Attributes
```typescript
// Bad
<button onClick={handleDelete}>
  <TrashIcon />
</button>

// Good
<button onClick={handleDelete} aria-label="Delete task">
  <TrashIcon />
</button>
```
